พระราชบัญญัติจัดตั้งศาลปกครองและวิธีพิจารณาคดีปกครอง พ.ศ.2542 มาตรา 9 วรรคหนึ่ง (2) บัญญัติว่า ศาลปกครองมีอำนาจพิจารณาพิพากษาหรือมีคำสั่งในคดีพิพาทเกี่ยวกับการที่หน่วยงานทางปกครองหรือเจ้าหน้าที่ของรัฐละเลยต่อหน้าที่ตามที่กฎหมายกำหนดให้ต้องปฏิบัติหรือปฏิบัติหน้าที่ดังกล่าวล่าช้าเกินสมควร และมาตรา 42 วรรคหนึ่งบัญญัติว่า ผู้ใดได้รับความเดือดร้อนหรือเสียหายหรืออาจจะเดือดร้อนหรือเสียหายโดยมิอาจหลีกเลี่ยงได้อันเนื่องจากการกระทำหรือการงดเว้นการกระทำของหน่วยงานทางปกครองหรือเจ้าหน้าที่ของรัฐ หรือมีข้อโต้แย้งเกี่ยวกับสัญญาทางปกครอง หรือกรณีอื่นใดที่อยู่ในเขตอำนาจศาลปกครองตามมาตรา 9 และการแก้ไขหรือบรรเทาความเดือดร้อนหรือความเสียหายหรือยุติข้อโต้แย้งนั้น ต้องมีคำบังคับตามที่กำหนดในมาตรา 72 ผู้นั้นมีสิทธิฟ้องคดีต่อศาลปกครอง
